Privacy Policy

Effective date: 28 November 2026

Important: This build has no central account service or private backend. Browser storage is not encrypted. A Gemini API key entered here is available to the running page and is sent to Google when Gemini is used. Do not enter sensitive or high-privilege credentials.

Information stored on your device

The app may store tasks, calendar entries, saved messages, notes, contacts, memories, macros, interface preferences, and a manually selected location in browser local storage. Anyone with access to the browser profile or device may be able to read this data. Clearing site data may erase it.

External providers

  • Google Gemini: When enabled with your own key, question text is sent directly from the browser to Google's Generative Language API. The key is held in page memory and sent in a request header. This is not a secure vault. Do not bundle a shared production key in this client-side app.
  • DuckDuckGo and Wikipedia: Online lookups send the requested search term to these providers.
  • Open-Meteo: A city you search for is sent to its geocoding API. After you request GPS and grant browser permission, coordinates are sent to Open-Meteo for weather.
  • OpenStreetMap Nominatim and BigDataCloud: After a GPS request, coordinates may be sent to Nominatim for reverse geocoding and to BigDataCloud only as a fallback if the first provider does not return a city label.
  • ipify: The optional public IP lookup contacts ipify only after you tap the lookup control. ipify receives your public source IP and standard request metadata. The result is held in page memory only and is not stored by JARVIS.
  • Cloudflare speed test: The optional quick test downloads about 1 MiB and uploads about 256 KiB to Cloudflare. Cloudflare receives your public source IP, connection metadata, and measurement traffic. The app does not save the result. The test may use mobile data.
  • Apple iTunes Search: Media search terms are sent to Apple's API. Artwork and previews may load from Apple-hosted URLs.
  • Google Fonts, Tailwind CDN, and cdnjs: Fonts and libraries are loaded from these providers, which receive standard request metadata, including IP address and browser information.
  • External app links: Opening Google, YouTube, WhatsApp, Gmail, Calendar, or another service sends you to that provider. Its own privacy terms apply.

Network diagnostics

Public IP lookup and speed testing are off by default and run only after a user action and confirmation. Public IP lookup uses ipify. The quick speed test uses Cloudflare endpoints and transfers approximately 1.25 MiB in total. These providers can observe the request source IP and associated network metadata. JARVIS keeps the displayed public IP and test results in page memory only; it does not persist them. The browser build does not expose a local/private LAN IP.

Microphone, camera, and location

GPS is requested only after you tap Request GPS, confirm the disclosure, and grant the browser permission. A GPS fix is kept in memory for the current session and is not saved by JARVIS. The coordinates are sent to the listed reverse-geocoding and weather providers. Manual city search sends the city name to Open-Meteo. Browser speech recognition may be processed by the browser or operating-system provider. You can deny or revoke permissions in device or browser settings.

Files

The local file inspector reads selected files in the browser to display basic image dimensions or text statistics. It does not upload files as part of that inspection flow. Text you paste into an online question or search may be sent to the relevant provider.

Security and retention

Workspace data is not encrypted by this app. The optional Gemini key is held in page memory, but this does not protect it from browser extensions, device inspection, or other scripts running in the page. This build has no server-side proxy for production API keys. We cannot guarantee zero data exposure or the security of third-party services, devices, or networks. Android backup is disabled in this build, but this is not a complete security review.

To remove local workspace data, clear this site's storage in your browser or clear the app's data in Android settings. Close the page or app to clear the current in-memory key.

Policy updates and privacy requests

Update this policy whenever providers, analytics, server storage, account features, or uploads change. For privacy requests, use the official support channel through which the app is distributed. Do not post credentials or private information in public issue trackers.
